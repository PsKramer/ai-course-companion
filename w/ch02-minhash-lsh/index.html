S-curve P(s) = 1 − (1 − sr)b: chance that a pair with Jaccard s shares at least one band. Dashed line: threshold (1/b)1/r. Orange line: this pair's J. Purple dots: catch rate from your 40-trial runs.

What to notice

Banding turns a fuzzy similarity into a sharp yes/no around a threshold you choose with b and r. A few percent of edited words already drops J to about 0.7, because each edited word breaks up to n shingles. More rows per band (with more bands to compensate) make the step steeper but cost more hashes.
Model. Shingles = the set of consecutive n-word sequences (lower-cased). J = |A ∩ B| / |A ∪ B|. Each shingle is hashed to a 31-bit integer x. MinHash value j = min over shingles of (aj·x + cj) mod p, with p = 231 − 1 and random aj, cj, so two documents agree on value j with probability J. The k = b·r values are cut into b bands of r rows, and a pair becomes a candidate duplicate if any whole band matches. Edits replace randomly chosen words using a fixed seed, so results are reproducible.
